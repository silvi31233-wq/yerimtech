# YERIM TECH — 예림테크 홈페이지

수처리 장치와 산업용 파쇄기를 소개하는 반응형 기업 홈페이지의 초기 시안입니다.

## 실행
별도 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.

## 파일
- `index.html`: 메인 페이지 및 콘텐츠
- `styles.css`: 디자인과 모바일 반응형 스타일
- `script.js`: 모바일 메뉴 및 연도 표시

## 주의
현재 이미지와 기술 소개 문구는 **디자인용 예시**입니다. 실제 제품 사진, 사양, 회사 주소, 연락처, 인증 및 실적은 확인 후 반영해야 합니다. 문의 버튼은 아직 비활성화되어 있습니다.

## 배포
GitHub Pages 등 정적 웹 호스팅에 배포할 수 있습니다. Private 저장소의 GitHub Pages 사용 가능 여부는 계정 플랜과 설정에 따라 달라질 수 있습니다.
